# Yash Bohra: Personal Portfolio
Hand-coded with HTML, CSS and JavaScript. No frameworks, no builder tools.

**Live site:** https://yashbohra858-sketch.github.io/yash-portfolio/

## Edit
- Links and resume: top of `main.js` (`CONFIG`). Empty values stay hidden.
- Project case studies: `P` in `main.js`. Add photos with `gallery:["assets/photo.jpg"]`.
- Profile photo: replace `assets/profile.jpg` (keep the name).

## Deploy (GitHub Pages)
Push to a public repo, then Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
